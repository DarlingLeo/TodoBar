使用说明

  • 「今日待办」显示活跃的待办:从添加当天起,到截止日期当天止,每天都出现;过了截止日还没完成的,转入底部「提醒列表」(可折叠,跨日期累计)。
  • 点击顶栏日期 → 选历史日期 → 查看该日「活跃待办 / 该日已完成 + 提醒列表(累计)」。
  • 点击待办上的截止时间(如"截止 今天 17:00"/"长期有效")→ 行内修改日期/时间,改完自动归位(改到明天就显示在明天待办里,不会进提醒)。
  • 右上角 布局按钮:上下(待办在上/已完成在下)⇄ 左右(两列并排)切换,选择会记住。
  • 勾选框打勾 → 标完成,完成时间 = 点击时刻。
  • 新增时:日期时间都不选 = 长期有效(每天显示直到完成);只填时间 = 当天该时刻截止;选了日期 = 该日截止。
  • 拖窗口出屏幕边缘自动贴边成小图标,点击展开。
  • 点击 🗑 删除待办,删除后不再保留记录。
  • 点击 ✕ 隐藏到托盘;托盘图标右键可退出。
